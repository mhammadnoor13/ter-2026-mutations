divide(int,int) — survived

R ✓ mais I ✗ : l'entrée (0,5) est un point fixe pour la mutation AOR.

Analyse de l'infection

// Mutation AOR :
return a / b;   // original
return a * b;   // mutant

// Test actuel : divide(0, 5)
//   original : 0 / 5 = 0
//   mutant   : 0 * 5 = 0  ← identique !  I ✗

// Test tueur : divide(6, 2)
//   original : 6 / 2 = 3
//   mutant   : 6 * 2 = 12  ← différent !  I ✓
Diagnostic I ✗ : Tout appel avec a == 0 est neutre pour cette mutation. Choisir des entrées non nulles telles que a/b ≠ a*b.

Fix 1 — multiply() : P ✗ → P ✓

Avant

calc.multiply(4, 3);
assertTrue(true);  // assertion inutile

Après

assertEquals(12, calc.multiply(4, 3));  // P ✓
assertEquals( 0, calc.multiply(5,  0));
assertEquals(-6, calc.multiply(-2, 3));
Règle P : Asserter la valeur de retour exacte avec assertEquals. Un assertTrue(x != null) ou assertTrue(true) ne capte aucune mutation sur la valeur retournée.

Fix 2 — max() : R ✗ → R ✓

Tests à ajouter

@Test void max_premierPlusGrand()  { assertEquals(5, calc.max(5, 3)); }
@Test void max_deuxiemePlusGrand() { assertEquals(7, calc.max(2, 7)); }
@Test void max_egaux()             { assertEquals(4, calc.max(4, 4)); }
// max(4,4) distingue  a > b  de  a >= b  (mutation ROR)
Règle R : Toute ligne rouge dans JaCoCo = R ✗. Ajouter un test d'appel avant d'analyser I et P.

Fix 3 — divide() : I ✗ → I ✓

Remplacer l'entrée neutre

assertEquals(0, calc.divide(0, 5));  // 0/5 == 0*5 → I ✗

assertEquals(3, calc.divide(6, 2));  // 6/2=3 ≠ 6*2=12 → I ✓
assertEquals(2, calc.divide(7, 3));  // 7/3=2 ≠ 7*3=21 → I ✓
Règle I : Éviter les entrées à zéro et les cas symétriques (a == b pour +/-). Choisir des valeurs telles que f_original(a,b) ≠ f_mutant(a,b).
