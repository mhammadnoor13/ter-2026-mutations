# TER-2026-mutations - Analyse de mutation et modèle RIPR

Par Ali Mhammad Nour, Baptiste Girard, Cédric Fouchard et Louis Boulanger

## Description

Projet de recherche du parcours ALMA du master informatique.

Ce dépôt contient le travail réalisé dans le cadre du TER 2026.
L’objectif est d’analyser les mutants survivants générés par PIT en s’appuyant sur le modèle RIPR afin de mieux comprendre les limites des suites de tests et d’aider le testeur à les améliorer.

Le projet s’appuie sur une base issue du TER 2025.
